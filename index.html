Framework Overview

Five calibrated frameworks govern how FinSoko agents operate, remember, hand off, stay safe, and learn.

RANK

Defines each agent’s Role, Authority limits, Notification triggers, and Kill switch.

  • Role What the agent does
  • Authority Decision limits (e.g., max KES 15k)
  • Notification What triggers the agent
  • Kill switch Emergency stop command

TRAIL

Controls memory using Transient, Relational, Archival, Inheritance, and Land Rights.

  • Transient Session-only memory
  • Relational Linked member context
  • Archival Permanent audit records
  • Inheritance Rules passed between agents
  • Land Rights Data sovereignty by region

HUNT

Defines Handoff triggers, Unified context, Negotiation rules, and Termination conditions.

  • Handoff When agents transfer control
  • Unified Shared context packet format
  • Negotiation Rules for agent disagreement
  • Termination End-of-escalation rules

GUARD

Adds Guardrails, Unusual detection, Audit trail, Red team testing, and Dignity preservation.

  • Guardrails Hard limits on agent behavior
  • Unusual Anomaly detection patterns
  • Audit Full decision trail logging
  • Red team Adversarial test cases
  • Dignity Respect-preserving language

CYCLE

Captures outcomes, yields insights, proposes correction, requires validation, and explains changes.

  • Capture Record all outcomes
  • Yield Extract performance insights
  • Course correct Adjust agent parameters
  • Human validate Officer review required
  • Explain Transparent change logs

Safety Rails

Built-in protections to ensure fair, transparent, and human-accountable lending decisions.

  • Gender, ethnicity, and county proxies cannot be used as denial reasons.
  • Denial-rate anomaly above 30% triggers automatic review.
  • Every recommendation and handoff is logged with full audit trail.
  • Red-team cases include women vendors, rural farmers, shea butter traders, and seasonal earners.
  • Human officer makes the final decision — always.
  • Member appeal rights remain available at every stage.
